#  Elimu AI — Your Kenyan Student Study Companion

Elimu AI is a free, AI-powered chatbot designed to help Kenyan primary and secondary school students (ages 6–18) with academics, exam preparation, and mindset development.

##  Features

-  **Homework Help** — Step-by-step explanations for all CBC & 8-4-4 subjects
-  **Mindset Coaching** — Growth mindset, resilience, and self-belief lessons
-  **Exam Prep** — KCPE and KCSE tips, study strategies, and revision guidance
-  **Just Chat** — Career guidance, peer pressure, and life advice
-  **Kenyan Context** — Local examples, Swahili phrases, and African role models
-  **XP System** — Students earn points for every question asked
-  **Daily Quotes** — Inspirational quotes from Wangari Maathai, Eliud Kipchoge, and more

##  Tech Stack

- **Frontend**: React + TypeScript + Vite
- **AI**: Groq API (Llama 3.3 70B)
- **Deployment**: Vercel
- **Styling**: Custom CSS with dark cosmic theme

##  Getting Started

### Prerequisites
- Node.js 18+
- Groq API key (free at [console.groq.com](https://console.groq.com))

### Installation

```bash
git clone https://github.com/Maxoti/elimu-ai.git
cd elimu-ai
npm install
```
